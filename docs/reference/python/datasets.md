# Datasets to try

`mosaica.datasets` fetches a dataset from its publisher, prepares the files its declaration names, builds the database and opens it, skipping each step whose output is still current. [Datasets to try](../../start/datasets.md) lists the datasets with their views, fields, layers and sizes, and `mosaica demo NAME...` runs `load` for each and opens their map in a browser. The datasets that are downloaded and prepared need the `demo` extra, `mosaica[demo]`.
